# معماری گره‌گشا — سند فاز صفر

> مالک و معمار: **حسین بختیاری** | نسخه‌ی سند: ۰٫۱٫۰

## ۱) لایه‌بندی

| لایه | پوشه | مسئولیت |
|---|---|---|
| ارائه (UI) | `lib/ui/` | صفحات، ویجت‌ها، پوسته‌ی ناوبری واکنش‌گرا |
| مدیریت حالت | `lib/providers/` | Notifierهای Riverpod (تم، و بعداً داده‌ها) |
| سرویس‌ها | `lib/services/` | فایل `.psp`، تنظیمات محلی؛ آینده: هوش مصنوعی آفلاین، گفتاربه‌متن |
| داده | `lib/data/` | SQLite (اسکیمای نسخه‌بندی‌شده)، مدل‌های دامنه؛ آینده: لایه‌ی مخازن (Repository) |
| هسته | `lib/core/` | تم، رنگ‌های برند، ثابت‌ها، ابزارهای فارسی |

## ۲) تصمیم‌های کلیدی

| تصمیم | انتخاب | دلیل |
|---|---|---|
| مدیریت حالت | **Riverpod** | مقیاس‌پذیر برای ۶۶ ویژگی، تست‌پذیر، بدون وابستگی به درخت ویجت |
| دیتابیس | **sqflite + sqflite_common_ffi** | یک لایه‌ی کد مشترک برای اندروید و ویندوز، بدون نیاز به کدجن |
| انعطاف‌پذیری | ستون `metadata` (JSON) + `feature_flags` + مهاجرت نسخه‌ای | افزودن ویژگی‌های آینده بدون شکستن ساختار موجود |
| بسته‌ی پروژه | `.psp` = ZIP خالص با کتابخانه‌ی `archive` | بدون وابستگی به ابزار سیستمی؛ یکسان روی هر دو پلتفرم |
| فارسی‌سازی | `locale: fa` + فونت وزیرمتن + `initializeDateFormatting('fa')` | تقویم شمسی و جهت راست‌به‌چپ به‌صورت سراسری |

## ۳) استراتژی مقیاس‌پذیری به ۶۶ ویژگی

1. **`metadata` در همه‌ی جداول تجاری:** هر ویژگی آینده (نتایج ۵چرا، خروجی FMEA، DNA مسئله و…) داده‌ی خود را بدون `ALTER TABLE` ذخیره می‌کند.
2. **`feature_flags`:** هر قابلیت جدید با یک کلید روشن/خاموش می‌شود؛ انتشار تدریجی بدون ریسک.
3. **مهاجرت نسخه‌ای:** افزایش `Schema.version` + یک بلوک در `DatabaseHelper._onUpgrade`.
4. **`audit_trail` با `entity_type`:** همین جدول واحد، تاریخچه‌ی همه‌ی موجودیت‌های آینده را پوشش می‌دهد.

## ۴) مشخصات فرمت `.psp`

```
نمونه.psp (ZIP)
├── manifest.json       # format: "gereh-gosha-psp"، format_version، app_version،
│                       # schema_version، created_by: حسین بختیاری، exported_at (UTC ISO-8601)
├── database.sqlite     # کپی کامل دیتابیس (اتصال قبل از کپی بسته می‌شود)
└── attachments/        # بازتاب پوشه‌ی پیوست‌ها با مسیر نسبی
```

**ایمنی ایمپورت:** اعتبارسنجی فرمت از روی مانیفست، محافظت در برابر مسیرهای مخرب (Path Traversal)، پشتیبان‌گیری خودکار از دیتابیس فعلی قبل از جایگزینی، و ثبت رویداد در `audit_trail`.
