# 🔧 مستندات فنی گره‌گشا — برای توسعه‌دهندگان

معماری: **Clean Architecture آفلاین** | زبان: دارت/فلاتر | دیتابیس: اس‌کیولایت

## ۱. لایه‌ها

```
lib/
├── core/                    ← لایه‌ی هسته (بدون وابستگی به فریم‌ورک رابط)
│   ├── ai/ai_engine.dart        موتور هوش مصنوعی آفلاین (تی‌اف-آی‌دی‌اف + کسینوس)
│   ├── gamification/            سرویس امتیاز و نشان
│   ├── theme/                   رنگ‌ها، تایپوگرافی، تم روشن/تاریک
│   └── utils/                   فارسی‌سازی، آمار، موتور فرمول
├── data/
│   ├── database/                اسکیمای نسخه ۴ + مهاجرت‌ها
│   ├── models/                  مدل‌های مسئله/سطح۲/سطح۳
│   └── repositories/            تنها نقطه‌ی دسترسی به دیتابیس
├── features/
│   ├── level1..level3/          ویزارد‌های سه سطح (ارائه + حالت)
│   └── insights/                ابزارهای هوشمند فاز ۴
├── services/                    ← لایه‌ی سرویس (نقطه‌ی اتصال آینده به ای‌آر‌پی/سی‌ام‌ام‌اس)
│   ├── security/                رمزنگاری و سطوح دسترسی
│   ├── sharing/                 کیو‌آر/شبکه محلی/اشتراک بومی
│   └── خروجی‌ها                 ورد/اکسل/پی‌دی‌اف/اچ‌تی‌ام‌ال
└── ui/                          پوسته، صفحات عمومی، ویجت‌ها
```

## ۲. تصمیم‌های کلیدی

| موضوع | تصمیم | دلیل |
|-------|-------|------|
| هوش مصنوعی | تی‌اف-آی‌دی‌اف + شباهت کسینوسی روی دیتابیس محلی | بدون مدل خارجی، بدون اینترنت، یادگیری از تاریخچه سازمان |
| فارسی در پی‌دی‌اف | رندر صفحه روی بوم ← پی‌ان‌جی ← پی‌دی‌اف | شکل‌دهی صحیح حروف فارسی |
| خروجی ورد | سازنده دستی او‌او‌ایکس‌ام‌ال با راست‌چینی | بدون وابستگی به آفیس |
| رمزنگاری | ای‌ای‌اس-۲۵۶-سی‌بی‌سی + مشتق‌سازی کلید ۱۰هزار دور | استاندارد و آفلاین |
| حالت | ریورپاد + ذخیره خودکار در هر تغییر | سادگی و بازیابی پس از کرش |
| جستجو | اف‌تی‌اس۵ با جایگزین لایک | سرعت + سازگاری |

## ۳. اسکیمای دیتابیس (نسخه ۴)

جداول اصلی: یوزرز، پرابلمز، اکشنز، اتچمنتز، آدیت‌تریل، نالج‌بیس، اپ‌ستینگ،
فیشبون‌نودز، پارتودیتا، گنت‌تسکز (نسخه ۲)، تیم‌مبرز/اف‌ام‌ای‌آی/استتیستیکال‌دیتا/
پوق‌ماتریکس/پایلوت‌ریزالتز/کوپک/لسنز‌لرند (نسخه ۳)،
کاستوم‌ویزاردز/پولز/پول‌وتز + ستون آرشیو (نسخه ۴).

مهاجرت‌ها در `database_helper.dart` — هر نسخه فقط افزودنی است؛ داده هرگز حذف نمی‌شود.

## ۴. قرارداد پلاگین

هر پلاگین پوشه‌ای محلی با `plugin.json`:

```json
{
  "id": "oil-gas",
  "name": "ابزار نفت و گاز",
  "industry": "نفت و گاز",
  "version": "1.0.0",
  "entry_points": ["checklists/"],
  "enabled": true
}
```

ثبت/اسکن با `PluginRegistry.discover(pluginsDir)`.

## ۵. نقاط اتصال آینده (ای‌آر‌پی/سی‌ام‌ام‌اس)

همه‌ی ذخیره‌ها از مخازن (`*_repository.dart`) عبور می‌کنند؛ برای اتصال به
سیستم خارجی کافی است پیاده‌سازی جایگزین همان اینترفیس‌ها نوشته شود —
بدون تغییر لایه ارائه.
