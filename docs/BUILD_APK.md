# 📱 ساخت فایل نصبی اندروید — دو راه ساده

## راه اول: اسکریپت یک‌کلیکی (روی سیستم خودتان)

فقط کافی است فلاتر نصب باشد؛ سپس:

- **ویندوز:** روی `build_apk.bat` دابل‌کلیک کنید
- **لینوکس/مک:** `bash build_apk.sh`

اسکریپت خودش همه کارها را می‌کند:
۱. اسکلت اندروید می‌سازد ۲. نام «گره‌گشا» و مجوز میکروفون را تنظیم می‌کند
۳. وابستگی‌ها و آیکون را می‌سازد ۴. نسخه‌ی انتشار را کامپایل می‌کند.

**خروجی نهایی:** `dist/GerehGosha-1.0.0.apk` — همین فایل را روی گوشی کپی و نصب کنید.

> ⚠️ این خروجی «بدون امضای رسمی» است و برای تست و استفاده شخصی کافی است؛
> برای انتشار در کافه‌بازار/مایکت طبق `docs/RELEASE.md` امضای رسمی بسازید.

## راه دوم: ساخت ابری گیت‌هاب (بدون نصب فلاتر) ⭐ پیشنهادی

1. پروژه را در یک مخزن گیت‌هاب قرار دهید:
   ```bash
   git init && git add . && git commit -m "گره‌گشا ۱.۰.۰"
   git remote add origin <آدرس مخزن> && git push -u origin main
   ```
2. در صفحه مخزن به تب **Actions** بروید و روی **ساخت فایل نصبی اندروید** →
   **Run workflow** بزنید (با هر پوش به شاخه اصلی هم خودکار اجرا می‌شود).
3. پس از چند دقیقه، فایل نصبی از دو جا قابل دریافت است:
   - **بخش Artifacts همان اجرا:** `GerehGosha-1.0.0.apk`
   - **صفحه Releases (لینک مستقیم و دائمی):**
     `…/releases/latest` → فایل `GerehGosha-1.0.0.apk`

> همین حالا آماده است:
> `https://github.com/bhosein859-cell/-/releases/download/v1.0.0/GerehGosha-1.0.0.apk`

### راهنمای نصب روی گوشی

1. فایل APK را روی گوشی دانلود کنید (یا با کابل کپی کنید).
2. روی فایل بزنید؛ اگر اندروید اجازه نداد، پیام «نصب از منابع نامعلوم» را
   برای مرورگر/فایل‌منیجر فعال کنید.
3. برای احراز سلامت فایل، هش SHA-256 آن در توضیحات Release آمده است.

> ℹ️ این فایل با «کلید دیباگ» امضا شده و برای استفاده شخصی کافی است؛
> برای انتشار در کافه‌بازار/مایکت طبق `docs/RELEASE.md` امضای رسمی بسازید.

## آنچه ساختِ ابری به‌صورت خودکار اصلاح می‌کند

فایل `tool/ci_patch_android.py` پیش از کامپایل، این موارد را روی اسکلت اندروید
اعمال می‌کند (نیاز نسخه‌های جدید فلاتر/افزونه‌ها):

- نام فارسی اپ («گره‌گشا») و مجوز `RECORD_AUDIO`
- اعلانِ `android.speech.RecognitionService` برای تایپ صوتی در اندروید ۱۱+
- فعال‌سازی core-library-desugaring (نیاز `flutter_local_notifications`)
- هم‌ترازیِ `compileSdk` همه‌ی افزونه‌ها با اپ (رفع خطای `checkReleaseAarMetadata`)
- حذف تست قالبیِ `flutter create` که به کلاس `MyApp` اشاره می‌کند

اگر می‌خواهید روی سیستم خودتان (راه اول) هم بدون خطا کامپایل شود، همین اسکریپت
را بعد از `flutter create` اجرا کنید:
```bash
flutter create --platforms=android --org ir.bakhtiari --project-name gereh_gosha .
python3 tool/ci_patch_android.py
flutter build apk --release
```
