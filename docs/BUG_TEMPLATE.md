# 🐞 قالب گزارش باگ — گره‌گشا

هر باگ باید با این قالب ثبت شود؛ باگ‌های بدون «گام بازتولید» در اولویت قرار نمی‌گیرند.

```
عنوان: [خلاصه کوتاه رفتار اشتباه]
شناسه: BUG-####
تاریخ: ۱۴۰۴/--/--
گزارش‌دهنده: [نام]
نسخه اپ: ۱٫۰٫۰ (بیلد ---)
پلتفرم: ویندوز ۱۱ / اندروید ۱۳ / ...
فاز/ماژول: [مثلاً ویزارد سطح ۳ — گام ۴ اف‌ام‌ای‌ای]

اولویت:
  ⛔ بحرانی (از دست رفتن داده/کرش) — رفع در همان روز
  🔴 بالا (اختلال در قابلیت اصلی) — رفع تا ۲ روز
  🟡 متوسط (رفتار غیرمنتظره با راه‌حل جایگزین) — نسخه بعد
  ⚪ کم (ظاهری/نگارشی) — هر زمان

گام‌های بازتولید:
  ۱. ...
  ۲. ...
  ۳. ...

رفتار مورد انتظار: ...
رفتار مشاهده‌شده: ...
فایل‌های پیوست: (اسکرین‌شات/ویدیو/فایل .psp)
تکرارپذیری: همیشه / گاهی / یک‌بار
```

## جریان رسیدگی

1. **ثبت** با قالب بالا
2. **اولویت‌بندی** توسط مسئول کیفیت
3. **رفع** روی شاخه مجزا + تست واحد مربوطه
4. **تست مجدد** دقیقاً با همان گام‌های بازتولید
5. **بستن** با ذکر شماره کامیت/تغییر

## تعریف «انجام‌شده»

- باگ روی هر دو پلتفرم تست مجدد شود
- هیچ باگ بحرانی/بالای باز در زمان انتشار وجود نداشته باشد
