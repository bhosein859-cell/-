# گره‌گشا (Gereh-Gosha) — فاز صفر: زیرساخت

> **از گره تا راه‌حل؛ قدم‌به‌قدم، آفلاین و امن**
> ساخته شده با افتخار توسط **حسین بختیاری**

نرم‌افزار آفلاین حل مسئله‌ی سه‌سطحی برای ویندوز و اندروید با یک کدبیس مشترک Flutter.

## ✅ پیاده‌سازی‌شده در فاز صفر

- اسکلت کامل پروژه با معماری لایه‌ای (core / data / services / providers / ui)
- دیتابیس SQLite با اسکیمای مقیاس‌پذیر (۶ جدول تجاری + ۲ جدول زیرساختی) و پشتیبانی هم‌زمان اندروید و ویندوز
- فرمت فایل اختصاصی **`.psp`** (آرشیو ZIP شامل دیتابیس + پیوست‌ها + مانیفست) با قابلیت خروجی/ورودی
- پوسته‌ی رابط کاربری کاملاً **فارسی و راست‌به‌چپ** با فونت وزیرمتن
- ناوبری واکنش‌گرا: منوی کناری در دسکتاپ، منوی پایین در موبایل
- تم روشن/تیره با رنگ‌های برند (آبی نفتی #1E3A8A و نارنجی #F97316)
- صفحه شروع، داشبورد، ویزارد انتخاب سطح (۳ سطح)، پروژه‌های فعال، بانک دانش، تنظیمات و درباره‌ما
- لوگوی برند (گره‌ی در حال باز شدن → چرخه‌ی حل مسئله) به‌صورت SVG و PNG

## 🛠 پیش‌نیازها

- فلوتر استیبل (پیشنهاد: 3.24 یا بالاتر)
- برای خروجی ویندوز: ابزارهای بصری (طبق [مستندات رسمی فلوتر](https://docs.flutter.dev/platform-integration/windows))

## 🚀 راه‌اندازی

```bash
# ۱) تولید پوشه‌های پلتفرم (اندروید و ویندوز) در همین دایرکتوری
flutter create . --project-name gereh_gosha --org ir.bakhtiari --platforms android,windows

# ۲) دریافت وابستگی‌ها
flutter pub get

# ۳) تولید آیکون اپ از روی لوگو
dart run flutter_launcher_icons

# ۴) اجرا در حالت توسعه
flutter run -d windows      # دسکتاپ ویندوز
flutter run                 # دستگاه/شبیه‌ساز اندروید

# ۵) ساخت فایل نصبی
flutter build apk --release        # اندروید → build/app/outputs/flutter-apk/
flutter build windows --release    # ویندوز → build/windows/x64/runner/Release/
```

## 🧩 فاز ۱: ویزارد سطح ۱ (حل سریع)

- ویزارد تمام‌صفحه‌ی ۴ مرحله‌ای: ثبت مشکل (با عکس دوربین/آپلود + اولویت) → ۵ چرا → اقدام فوری → بستن و تایید
- چک‌باکس «آیا مشکل برطرف شد؟»: بله = بستن مسئله با نشان سبز «انجام شده»؛ خیر = بازگشت خودکار به ۵ چرا
- ذخیره در جداول `Problems` (Level=1)، `Actions` و `Attachments`؛ پاسخ‌های ۵ چرا به‌صورت آرایه‌ی JSON
- خروجی گزارش **Word** (.docx راست‌به‌چپ با نام «حسین بختیاری») در پوشه‌ی Downloads

### مجوزهای اندروید (افزودنی به `android/app/src/main/AndroidManifest.xml`)

```xml
<uses-permission android:name="android.permission.CAMERA"/>
<!-- فقط برای اندروید ۹ و پایین‌تر؛ برای نوشتن مستقیم در Downloads عمومی -->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28"/>
```

> در اندروید ۱۰+ اگر دسترسی به Downloads عمومی ممکن نباشد، گزارش به‌صورت خودکار
> در پوشه‌ی امن اپ (`Android/data/.../files/Download`) ذخیره می‌شود.

## 🧩 فاز ۲: ویزارد سطح ۲ (متوسط و تیمی)

- ویزارد ۸ گامه با نوار پیشرفت افقی، جابه‌جایی آزاد، پنل کناری دسکتاپ (تیم/تاریخچه/پیوست‌ها) و ذخیره‌ی خودکار
- گام‌ها: تعریف 5W2H + تیم + KPI → استخوان‌ماهی تعاملی 6M (کلیک برای افزودن، Drag & Drop، زوم) + پارتو با درصد تجمعی خودکار → درخت ۵چرای چندشاخه‌ای با اتصال به استخوان‌ماهی → جدول اقدامات 5W2H + گانت چارت (نوار رنگی، زوم، اسکرول، فلش وابستگی) → اجرا (درصد تکمیل + موانع) → بررسی (نمودار قبل/بعد + درصد بهبود) → استانداردسازی (SOP + پیوست + تاریخ بازبینی) → گزارش نهایی
- جداول جدید: `fishbone_nodes`, `pareto_data`, `gantt_tasks` (مهاجرت خودکار نسخه ۱→۲)
- خروجی Word چندصفحه‌ای (صفحه عنوان با لوگو، خلاصه مدیریتی، نمودارها به‌صورت تصویر باکیفیت، جدول‌ها) + Excel چهارشیته — هر دو آفلاین و در پوشه Downloads

## 🧩 فاز ۳: ویزارد سطح ۳ (گسترده و بحرانی)

- انتخاب متدولوژی در ورود: **8D / DMAIC / A3 / KT (کپنر-تریگو) / RCA جامع** — برچسب هر ۱۲ گام مطابق متدولوژی تغییر می‌کند
- ویزارد ۱۲ گامه با گیت سخت: بدون تایید مدیر، عبور از گام مهار (Containment) ممکن نیست
- گام‌ها: تعریف 5W2H + تیم با نقش‌ها + بحرانیت + KPI → اقدام مهار با تایید مدیر → تحلیل آماری پیشرفته (هیستوگرام با Cp/Cpk، نمودار کنترل μ±3σ با تشخیص نقاط خارج از کنترل، پراکندگی با همبستگی پیرسون، جعبه‌ای با پرت‌های ۱٫۵×IQR + ایمپورت داده از Excel + تمام‌صفحه) → جدول **FMEA** با محاسبه‌ی خودکار RPN=S×O×D، اولویت‌بندی نزولی، پارتوی RPN و پیشنهاد اقدام برای RPN≥۱۰۰ → ریشه‌یابی جامع (استخوان‌ماهی ۶M + چراهای چندشاخه + جدول چهارخانه‌ای KT هست/نیست) → طراحی راه‌حل (طوفان فکری آفلاین + ماتریس وزنی **Pugh** با انتخاب خودکار راه‌حل برتر + تحلیل ریسک) → پایلوت با آزمون معناداری ولچ → **COPQ** چهار دسته‌ای با محاسبه‌ی صرفه‌جویی/ROI و تایید مدیر مالی → پیاده‌سازی (سوابق آموزش + تخصیص منابع) → استانداردسازی (تولید خودکار SOP + مستندات + تاریخ بازنگری) → درس‌آموخته‌ها با انتقال به بانک دانش → بستن پروژه (گیمیفیکیشن + تایید مدیر حامی)
- موتور آمار خالص در `lib/core/utils/statistics.dart`: میانگین، انحراف معیار، چارک‌ها، پرت‌ها، قابلیت فرایند، حدهای کنترل، همبستگی، رگرسیون و آزمون ولچ
- جداول جدید: `team_members`, `fmea_items`, `statistical_data`, `pugh_matrix`, `pilot_results`, `copq`, `lessons_learned` (مهاجرت خودکار نسخه ۲→۳)
- خروجی‌ها: گزارش جامع **Word** (جلد با لوگو + نام حسین بختیاری، فهرست، تمام نمودارها تصویر باکیفیت، جداول FMEA/Pugh/COPQ، امضاها) + **Excel پنج‌شیته** (داده خام، FMEA، Pugh، COPQ، اقدامات اصلاحی) + **بایگانی PDF** (رندر هر صفحه روی بوم برای شکل‌دهی صحیح فارسی)

## ✨ فاز ۴: ویژگی‌های خاص و هوشمندسازی

- **هوش مصنوعی آفلاین** (`core/ai/ai_engine.dart`): بدون مدل خارجی — با بردارهای فرکانس واژه و شباهت کسینوسی از مسائل بسته‌شده‌ی داخل دیتابیس یاد می‌گیرد؛ پیشنهاد ریشه، پیشنهاد «چرا»ی بعدی، پیشنهاد متدولوژی، دسته‌بندی خودکار، تحلیل احساسات، استخراج درس‌آموخته و تولید سوال پرتکرار
- **دی‌ان‌ای مسئله**: گراف تعاملی ارتباط مسائل (کلیک روی گره = جزئیات، رنگ = سطح)
- **ماشین زمان**: پخش ترتیبی تاریخچه‌ی هر پروژه با اسلایدر و دکمه‌ی پخش
- **شبیه‌ساز تأثیر** و **داشبورد زنده‌ی هزینه کیفیت پایین** (دونات + میله‌ای)
- **ترسیم قلمی** با ذخیره‌ی پی‌ان‌جی در پیوست‌ها + **گفتار به متن** + **اتاق جنگ** (تایمر/ایده/رأی)
- **ویزاردساز سفارشی**، **قالب‌ها**، **بایگانی**، **موتور فرمول کا‌پی‌آی**
- **جستجوی فراگیر** (اف‌تی‌اس۵)، **تقویم مهلت‌ها**، **اتاق فرمان**، **یادآور هوشمند**
- بازیابی خودکار پس از کرش، معماری پلاگین، خروجی اچ‌تی‌ام‌ال تعاملی، گیمیفیکیشن (نشان‌ها + جدول رتبه‌بندی)
- جداول جدید: `custom_wizards`, `polls`, `poll_votes` + ستون `is_archived` (مهاجرت نسخه ۳→۴)
